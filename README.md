# Sreerang P — Portfolio

A professional, responsive portfolio focused on software development, AI systems, and data science.

## Highlights

- Midnight navy design with a consistent electric-blue / ice-blue palette
- Professional introduction and education timeline: TKM College of Engineering and IIT Madras BS Data Science & Applications
- Five curated projects with problem, implementation, stack, and architecture case studies
- Selected milestones: HackerRank AI Orchestrator score, Local Brain MCP npm publication, and TKM Notes launch
- LinkedIn-derived credentials: Google's 5-Day AI Agents course and Gemini Certified University Student
- **One live GitHub element only:** the 52-week contribution heatmap; no profile, repository, follower, star, or other live counters
- Contact form backed by Google Forms, plus direct email and social links
- Keyboard-accessible navigation, command palette, responsive layout, and reduced-motion support
- Dependency-free static site — no build step required

## Run locally

Open `index.html` in a browser, or serve the repository root with any static HTTP server.

## Deploy

The site can be deployed as a static site on GitHub Pages or Vercel. For Vercel, use framework preset **Other**, leave the build command empty, and use the repository root as the output directory.

## Content accuracy

- Project details should match the corresponding repository implementation.
- The GitHub contribution heatmap is loaded from a public contribution-data endpoint. No other GitHub statistics are fetched or displayed.
- LinkedIn details are presented as selected, manually curated profile highlights; LinkedIn follower counts and other changing metrics are intentionally omitted.
- Do not add unverified testimonials, rankings, technologies, or performance metrics.
- A resume PDF is not currently included. The hero uses a **Request Resume** email link rather than a broken download button.

No API keys or private credentials belong in this repository or in client-side code.
