# Sreerang P — Portfolio

A single-page student portfolio with:
- Responsive design
- Scroll reveal animations
- Ambient cursor glow
- Scroll progress indicator
- Hover micro-interactions
- Live GitHub profile/repository data
- No build step

## Deploy on Vercel

1. Create a GitHub repository.
2. Upload `index.html`.
3. Import the repository into Vercel.
4. Framework preset: **Other**
5. Build command: leave empty.
6. Output directory: leave empty / root.
7. Deploy.

No Stitch API key belongs in this website. Keep Stitch credentials in local
environment variables or your MCP/agent configuration.
